# Global NGO Impact Summit — Dubai 2026

Premium static website designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a new GitHub repository, e.g. `global-ngo-impact-summit`.
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`, then Save.
6. GitHub will provide your public `.github.io` address.

## Suggested application fields

## Important

A static GitHub Pages site cannot securely verify or custody cryptocurrency payments. For production, use a trusted payment processor or a secure server-side verification workflow, and publish clear payment/refund terms.

## Google Forms registration
The website is prepared to hand applicants to Google Forms. Replace:
`https://docs.google.com/forms/d/e/YOUR_FORM_ID/viewform`
in `index.html` with the actual published Google Form URL.

Recommended Google Form fields:
- NGO / organization name
- Country
- Representative name
- Email
- Phone / WhatsApp
- NGO website/social profile
- Registration/certificate details
- Mission and impact summary
- Number of beneficiaries served
- Key project outcomes
- Presentation title
- Supporting document/file upload
- USDT transaction hash
- Consent/confirmation checkbox

For file uploads, Google may require respondents to sign in. Test the form from an applicant's perspective before publishing.
